# 1.3 Gambaran Umum Phase 2

Fitur-fitur berikut tidak termasuk dalam scope MVP (Phase 1). Roadmap Phase 2 dapat dimulai setelah Phase 1 stabil dan telah digunakan minimal 3 bulan.

| **Modul** | **Fitur Utama** | **Estimasi Durasi** |
| --- | --- | --- |
| LMS — Ruang Kelas Virtual | Integrasi Google Meet, link meeting per kelas, jadwal sesi online | 4–6 minggu |
| LMS — CBT (Ujian Online) | Buat soal (pilihan ganda, essay), kunci otomatis, hasil real-time | 6–8 minggu |
| LMS — Bank Materi | Upload PDF/video per mata pelajaran, dapat diakses siswa kapan saja | 3–4 minggu |
| Presensi Digital | Absensi via aplikasi (GPS/selfie), rekap per bulan, notifikasi alpa | 4–5 minggu |
| Konseling & BK | Catat pelanggaran/prestasi, skor poin, rekam jejak bimbingan konseling | 3–4 minggu |
| E-Library | Katalog buku digital, tracking peminjaman, notifikasi batas kembali | 4–5 minggu |
| Manajemen Inventaris | Pendataan aset sekolah (komputer, meja, lab), kondisi, lokasi | 3–4 minggu |
| Payroll Guru & Staf | Input komponen gaji, potongan, slip gaji PDF, riwayat pembayaran | 5–6 minggu |
| Payment Gateway | Integrasi Midtrans/Xendit untuk pembayaran SPP online oleh ortu | 4–6 minggu |
| WhatsApp API | Upgrade dari wa.me ke Fonnte/Meta Cloud API untuk pengiriman otomatis | 2–3 minggu |
| DAPODIK Export | Export data siswa dalam format kompatibel Dapodik Kemdikbud | 3–4 minggu |
